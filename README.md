# King Cartões

Site desenvolvido para atender as necessidades do cliente.

## 🛠️ Tecnologias Utilizadas

- **Next.js 14 (App Router)**: Framework React para desenvolvimento web.
- **TypeScript**: Tipagem estática em todos os componentes e dados.
- **TailwindCSS**: Utilitários CSS com design tokens próprios (dark + dourado).
- **Framer Motion**: Animações de entrada suaves conforme o scroll.
- **Formspree**: Envio do formulário de contato sem backend próprio.

## 🌟 Funcionalidades

- **Design Responsivo**: O site é totalmente responsivo e pode ser acessado em desktops, tablets e smartphones.
- **Identidade King of the Kings**: coroa dourada do logo original e o leão como plano de fundo da hero.
- **Seções**: hero, produtos, como funciona, portfólio, depoimentos, contato e rodapé.
- **Animações e Transições**: animações suaves de entrada que melhoram a experiência do usuário.

## 🎨 Design System

| Token | Valor |
| --- | --- |
| Fundo principal | `#0a0a0a` |
| Superfície | `#141414` |
| Fundo sutil | `#0d0d0d` |
| Dourado | `#c9a84c` |
| Texto | `#ffffff` / `rgba(255,255,255,0.5)` |
| Fonte | Inter (Google Fonts) |

## 📂 Estrutura

```
src/
├── app/            # layout, página e estilos globais
├── components/     # Navbar, Hero, Produtos, Portfólio, Depoimentos, CTA, Footer
└── lib/data.ts     # produtos, depoimentos, etapas e links
```
